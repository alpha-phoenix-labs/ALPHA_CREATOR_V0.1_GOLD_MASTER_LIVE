## Initial Production Failure

The first real OpenAI generation request reached the OpenAI API but failed with HTTP 400.

Root cause:

`temperature=0.45` was passed to `gpt-5-mini`, while that model accepted only the default temperature value in this API path.

Observed result:

- OpenAI request: HTTP 400
- ALPHA fallback activated correctly
- provider: `local-grounded-fallback`
- model: `deterministic-v0.1`
- persistent review package still created

This confirmed that the fallback mechanism worked, but the real OpenAI generation path was not yet operational.
